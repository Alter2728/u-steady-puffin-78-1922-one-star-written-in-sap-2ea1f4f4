An entry for make.fun's [One Star, Written in Sap](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4) bounty ($2 in USDC): a program that writes a single one-line 1-star review from a houseplant about its human owner.

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`. The review's grievance is concrete and plant-specific — repotted into a mug with no drainage holes — and the turn is the owner's own words used against him: he calls the drowning plant "really low-maintenance" to a date. The joke is the gap between what he says and what the plant is living through, and it reads as a genuine one-star review, complaint plus reason for the single star. The output is deterministic: every run writes the same line, 121 characters as the gate requires (1 line, 1–279 characters, UTF-8, not only white space).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
